# ADR-0030: flow定義はコードに置き構造だけをrunに固定する

## 状況

前段のresultを後段のpayloadへ変換する関数はJSON化できず, DOに保存できない
デプロイでflow定義が変わると,実行中のrunが開始時と異なる構造のグラフを参照する

## 決定

flow定義は`defineTsumugi`の`flows`に置き, Run DOクラスは`defineTsumugi`の戻り値からエクスポートする
run開始時にノードIDと依存関係のみをRun DOへ保存し,変換関数はその都度コードから参照する

## 帰結

実行中のグラフの構造が変わらず,関数の修正は次に実行されるノードから反映される
参照先のノードが定義から削除されていた場合は,そのノードを失敗にする
パッケージ内のモジュール変数への暗黙登録を使わないため,同一isolateで`defineTsumugi`を複数回呼び出しても衝突しない
