# ADR-0055: ランタイム依存を持たない

## 状況

Tsumugiはdrizzle-orm, hono, @paralleldrive/cuid2をランタイム依存として持っていた
利用者の依存ツリーにはTsumugiが要求するバージョンのパッケージが入り、利用者が同じパッケージの別バージョンを使う場合は重複管理が必要になる
利用者のプロダクトには、技術的な制約からdrizzle-ormのバージョンを変更できないものがある
公開型定義が依存パッケージの型を参照するため、利用者の型検査で型が衝突し得る
依存パッケージのコードは利用者のWorkerのバンドルに含まれ、gzip後でdrizzle-ormが約19KB, cuid2が約11KB, Honoが約7KBを占めていた
1.0未満のdrizzle-ormは、マイナーバージョンの更新でも破壊的変更への追従が必要になる
依存パッケージとその推移的依存は、利用者のサプライチェーンの範囲に加わる

## 決定

`dependencies`を持たず、必要な機能はTsumugi内に実装する
DOのSQLiteは`SqlStorage.exec`, D1は`prepare`と`batch`で、SQLを直接実行する
クエリの取得列はDDLとは別に定数で持ち、両者の一致はテストで検査する
REST APIのルーティングは、使用している機能だけを持つ内部のルーターで処理する
localIdは`crypto.getRandomValues`から生成する
外部ライブラリをバンドルへ同梱する方法は採らない, 同梱では公開型の参照とバンドルの重複が残る

## 帰結

利用者の依存ツリーと公開型定義に、Tsumugi由来の外部パッケージが含まれない
列名の誤記や型の不一致は、コンパイル時ではなくテストで検出する
SQL文の記述とルーティングの保守はTsumugi側で行う
`auth`の型はHonoのミドルウェアから独自の関数型へ変わる(ADR-0056)
