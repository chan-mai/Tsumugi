# ADR-0059: runに属するジョブの個別リトライを拒否する

## 状況

ジョブ単位のリトライ(Job DOの`retry`, REST APIの`POST /api/jobs/:id/retry`, ダッシュボード)は、ジョブがrunに属するかを確認していなかった
リトライ後のジョブはジョブIDが変わらないため、完了通知はRun DOでノードのジョブIDと一致し、FAILEDのノードをCOMPLETEDに上書きする
SKIPPEDの下流は再評価されず、下流を実行しないままrunがCOMPLETEDになる
COMPLETEDのrunは再開(ADR-0034)の対象外のため、下流は実行されないまま残る

## 決定

Job DOは、runに属するジョブのリトライを理由`in-run`で拒否する
REST APIは`in-run`を409で応答する
一括リトライでは、拒否したジョブを`in-run`の理由付きで結果に含める
条件を指定した一括リトライでは、runに属するジョブを対象から除外する
除外しないと拒否されたジョブが毎回対象に含まれ`remaining`が0にならない
runに属するジョブの再実行は、runの再開(ADR-0034)で行う

## 帰結

ジョブ単位のリトライで、runとノードの状態は変わらない
ダッシュボードのジョブ詳細では、runに属するジョブのリトライボタンを操作不可にする
ジョブ一覧の行メニューからのリトライでは、REST APIの409の応答メッセージが表示される
