# ADR-0058: 再開では未実行へ戻したノードの下流の成功済みノードも再実行する

## 状況

ADR-0034はrunの再開で成功済みのノードを再実行しないと決定済み
`trigger`が`failure`と`always`のノードは、上流の失敗後に実行されCOMPLETEDになる
再開で上流は再実行されるが、これらのノードはCOMPLETEDのまま残る
再開後に上流が再び失敗しても後処理は実行されず、`always`のノードは最後の試行の結果に対して実行されない
ADR-0041の「再開後の結果に応じて経路が選び直される」と一致しない

## 決定

再開では、未実行へ戻したノードを依存先に持つCOMPLETEDのノードも未実行へ戻す
この判定を下流へ推移的に適用する
`trigger`の値は問わない, 後処理が再実行されると、その下流の`success`のノードも入力が変わるため
fan-out, subflow, spawnで子を作成したノードは対象外とし、COMPLETEDのまま残す
fan-outとspawnの子は同じノードIDで再作成するため、既存の子の削除とD1の投影からの削除が必要になる
subflowの子runのIDは親のrunIDとノードIDから決まり(ADR-0029)、COMPLETEDの子runが残っている間は再実行されない

## 帰結

後処理と監査のノードは、最後の試行の結果に対して実行される
後処理のノードのperformerは、再開のたびに再度実行される
子を持つ後処理のノードは再開で再実行されない
