# ADR-0034: 失敗したrunは失敗したノードから再開する

## 状況

FAILEDとSTALLEDは終端だが不可逆ではない(ADR-0012), ジョブは手動リトライを受け付ける期間を持つ(ADR-0027)
100ノードのうち1つが失敗しただけで先頭から再実行すると,冪等でないperformerが2回実行される

## 決定

runの再開では,失敗したノードを新しいジョブとして再作成し, SKIPPEDにした下流をPENDINGへ戻す
成功済みのノードは再実行しない
Run DOの保持期間もジョブと揃え,終了したrunは短く,失敗したrunは7日保持する

## 帰結

再開を受け付ける期間と,画面に表示される期間が一致する
ノードは最後に実行したジョブIDを保持し,過去の試行はジョブ側の履歴に残る
