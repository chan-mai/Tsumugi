# ADR-0035: runを跨ぐデータと規模に上限を設ける

## 状況

resultは上限を超えるとnullになる(#9), DAGではこれが後段のpayloadの材料になる
fan-outとspawnは実行時にノードを追加するため,上限がないとDOのSQLiteとtickが破綻する

## 決定

run所属ジョブのresultが上限を超えた場合は,成功ではなく理由を付けた失敗にする
fan-outの結果は件数と成否の集計値のみを後段へ渡し,子ノードごとのresultは渡さない
1つのrunに含めるノード数に既定の上限を設け,超過した時点でrunを失敗にする

## 帰結

nullが下流へ渡ることがなくなり,大きい結果はR2等へ書き込んで参照のみを返す運用になる
展開数が増加しても後段の入力サイズが一定に保たれる
