# ADR-0031: ジョブ完了はアウトボックスで通知し進行はalarmで行う

## 状況

Job DOからRun DOへの通知が1回でも失われると, runは進行しなくなる
Job DOのtickがRun DOを呼び出し,そのRun DOが同じJob DOへノードを投入すると呼び出しが入れ子になる

## 決定

完了とspawn要求をJob DOの通知アウトボックスへ記録し, tickがRun DOへ送信して成功後に削除する
Run DOは受信した通知を記録して即座に応答し,ノードの投入は自身のalarmで行う

## 帰結

送信に失敗しても次のtickで再送される, D1への投影と同じ構成(ADR-0008)
DO間の呼び出しが常に一方向になり,再入時の動作を保証する必要がない
完了から次のノードの起動までalarm 1回分の遅延が発生する
