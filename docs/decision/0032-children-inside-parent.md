# ADR-0032: 実行時に追加したノードは親ノードの配下に置く

## 状況

fan-outの展開とperform内のspawnは,どちらも実行時にノードを追加する
追加したノードを親と同じ階層に置くと,後続のノードが追加された処理の完了を待てない

## 決定

実行時に追加したノードは親ノードの子として保持し,親は自身と子孫がすべて終端状態に達した時点で完了とする
fan-outとspawnは同じ機構で表現する
子ノードのIDはspawnでは利用者が明示し, fan-outでは要素の添字を既定とする

## 帰結

`after`で親を指定したノードは,子孫の完了も自動的に待つ
状態機械が1つで済み,画面も入れ子の構造でそのまま表示できる
同じIDの再spawnは新規作成せず既存を返すため, at-least-onceの再実行でも重複しない
