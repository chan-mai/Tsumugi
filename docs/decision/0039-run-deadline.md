# ADR-0039: run全体の期限で止まったrunを打ち切る

## 状況

期限はノード単位のtimeoutMsしか無く, 進行が止まったrunはRUNNINGのまま残る(#33)
掃除の対象は終端に達したrunなので, 止まったrunは保持期間による削除も受けない(ADR-0034)

## 決定

期限はflow定義の`deadlineMs`を既定とし, startの指定を優先する
超過したrunは取り消しと同じ手順で打ち切る, 未起動と実行前を止め, 実行中のジョブは自身のtimeoutMsによる終端を待つ
打ち切られたノードは理由付きのFAILEDになる
超過はRUNNINGの間に一度だけ印としてrunへ永続化し, 印の付いたrunは残りが全て成功していても決着をFAILEDにする
fan-outの子の失敗は非致命(ADR-0035)なので, ノードの状態からは期限による打ち切りを判別できない
時計から毎回判定すると決着済みのrunが掃除のtickでFAILEDへ反転するため, 印で持つ
実行中の子のrunは取り消す, 親が終わった後も動き続けるのを防ぐ
再開では期限を再開の時点から引き直し, 印を外す

## 帰結

止まったrunが期限後にFAILEDへ達し, 保持期間による削除の対象になる
実行中のジョブを外から中断する手段は増やさない, 取り消しがSCHEDULEDのみを受ける現状(ADR-0012)を保つ
期限の時点で決着していなかったrunは, 残りが全て成功してもFAILEDになる
